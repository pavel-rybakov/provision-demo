# Техническое задание Java компании Provision

## Назначение сервиса

Сервис предназначен для управления приборами учёта электроэнергии и передачи их показаний.

## Роли пользователей

Пользователь может иметь одну из двух ролей:

- **Администратор**
- **Менеджер**

## Функциональные требования

### Авторизация

- Пользователь может авторизоваться в сервисе.
- Методы API должны быть защищены посредством Bearer Token.
- Доступ к методам API должен проверяться в соответствии с ролью пользователя.

### Управление данными

| Функция | Администратор | Менеджер |
| --- | :---: | :---: |
| Управление пользователями | Да | Нет |
| Управление приборами учёта | Да | Нет |
| Управление показаниями приборов учёта | Да | Да |
| Импорт показаний из CSV | Да | Нет |

Под управлением подразумеваются следующие операции:

- создание;
- просмотр;
- редактирование;
- удаление.

### Экспорт и отправка показаний

Каждые две недели сервис должен:

1. Сформировать CSV-файл с последними показаниями всех приборов учёта.
2. Отправить сформированный файл на адрес `user@example.com`.

## Сущности

### Пользователь

| Поле | Описание |
| --- | --- |
| Email | Адрес электронной почты пользователя |
| ФИО | Полное имя пользователя |
| Пароль | Хранится в зашифрованном виде |
| Роль | Значение enum: администратор или менеджер |

### Токен авторизации

| Поле | Описание |
| --- | --- |
| Пользователь | Связь с пользователем |
| Токен | Значение токена авторизации |

### Прибор учёта

| Поле | Описание |
| --- | --- |
| Пользователь | Связь с пользователем |
| Серийный номер | Серийный номер прибора |
| Инвентарный номер | Инвентарный номер прибора |
| Год изготовления | Год изготовления прибора |
| Коэффициент трансформации | Коэффициент трансформации прибора |
| Дата установки | Дата установки прибора |
| Номер пломбы | Номер основной пломбы |
| Номер антимагнитной пломбы | Номер антимагнитной пломбы |
| Место установки | Место установки прибора |
| Примечание | Дополнительная информация |
| ID в ГИС ЖКХ | Идентификатор прибора в ГИС ЖКХ |

### Показание прибора учёта

| Поле | Описание |
| --- | --- |
| Прибор учёта | Связь с прибором учёта |
| Значения для зон | Показания по тарифным зонам |

## Требования к реализации

- Взаимодействие с сервисом осуществляется через REST API.
- Авторизация методов API осуществляется посредством Bearer Token.
- Доступ к методам API проверяется на основании роли пользователя.
- Методы API документируются в Swagger на русском языке.
- Таблицы и поля базы данных должны иметь русскоязычные описания.
- Функциональность должна быть покрыта тестами без излишнего углубления: один сценарий на каждый метод.

## Результат

Исходный код необходимо разместить в публичном репозитории любого удобного Git-сервиса.
